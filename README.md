# OKK STUDIO 1.0.20

Windows 多机位视频剪辑应用。本版增加调色时间线滚轮平移、缩放与逐帧定位。

本版提供曝光检测和 MCP 本机连接桥；外部 MCP 服务使用源码包及单独的 Python 环境，接入说明见 [MCP.md](MCP.md) 和 [EXPOSURE.md](EXPOSURE.md)。

**[下载 OKK-STUDIO-1.0.20-Setup.exe](https://github.com/lianduan683/OKK-STUDIO-1.0.0/releases/download/v1.0.20/OKK-STUDIO-1.0.20-Setup.exe)** · [发行页](https://github.com/lianduan683/OKK-STUDIO-1.0.0/releases/tag/v1.0.20)

主程序已内置安装器。安装时下载并校验 v1.0.0 的四份固定资源 ZIP（约 5.75 GB），完整安装约 6.5 GB，建议预留至少 15 GB。已有离线资源可通过 `/PAYLOADDIR` 复用。安装与升级见 [INSTALLATION.md](INSTALLATION.md)。

## 新增与修复

- 特效库提供分类、搜索与卡片拖放；支持将调色、叠加拖到片段，将转场拖到接缝。提供 137 个 PR 风格几何遮罩转场，属于近似适配；已从列表中移除不适合作为转场遮罩的图片条目，旧素材文件保留以兼容工程。

- 裁切窗口支持视频播放、逐帧和时间滑块；自动裁切分析当前帧，可优先使用合适代理预览；未选片段时可处理播放头处视频，点击时间线空白处可取消选择。

- 可根据当前帧自动检测黑边并进行 16:9 手动裁切、缩放和预览；裁切可撤销并保存，预览与导出使用同一构图。

- 选中多机位节目片段后点击画面或机位按钮可替换整段，未选中时在播放头处插入切点；时间线在播放、定位及逐帧时自动跟随。

- 面板支持浮动、四边停靠、标签合并与排序和整组拖动；成片监看可在所在屏幕全屏并恢复原布局。

- 本地曝光抽样及可选模型复核、机位匹配和调色导出。
- D 键启用 / 禁用片段，支持撤销和工程保存。
- 自动保存、快捷键设置及特效拖放到时间线。

- “文件 / 工程 → 导入时间线…”支持 XML、FCPXML、EDL、OTIO、AAF 和 MLT/Kdenlive 交换格式；可选择单条多机位视图或展开机位源轨，支持右键切换、素材重连、撤销和保存，详见 [时间线导入说明](TIMELINE_IMPORT.md)。

- “工程设置 → 预渲染”可开启自动缓存、选择保存目录及预设/自定义分辨率；刻度尺下沿以黄色显示预计可直接播放的区间，红色显示待渲染区间，完成校验后变绿并用于回放。暂停且空闲时自动处理，编辑后重新检查。
- 右下角“工程设置”提供时间线分辨率、帧率、音频采样率与位深；支持 48/96/192 kHz、24bit、32bit 和 32bit 浮点，设置随工程保存。
- 调色时间线支持滚轮水平平移、Ctrl＋滚轮围绕播放头缩放、Alt＋滚轮逐帧，以及中键拖动和适配全片。
- 调色页仅播放当前调色画面并使用原片，标准机位按需读取；返回剪辑页恢复机位网格的代理预览，保留代理设置。
- 多机位收起后可作为外层视频轨道排序，上方轨道可覆盖或叠加画面；切换编辑页面时保留标签、浮动窗口、分隔位置和视图。
- 多机位网格行列与页码随工程恢复，面板位置和分隔比例记住上次使用的布局；两侧监看标题显示各自实时播放 FPS。
- 向下滚动轨道时，时间刻度和播放头手柄始终可见并可拖动定位；右键视频、音频轨道可删除当前轨道或清理同类型空白轨道，支持撤销与保存。
- 素材列表逐视频显示代理状态图标；右键“转代理…”可选择 H.264、DNxHR LB、ProRes Proxy、分辨率、帧率及代理保存目录。
- 时间线“吸附”可控制光标吸附素材边缘与节目切点；“链接”可控制视频及机位原声成对编辑，A0 主音频保持独立。
- 底部“调音”提供混音台，调整后点击“处理并播放”更新离线试听；预览与导出使用相同处理。VST3 插件需在本机安装。
- 机位显示编号按素材库顺序连续排列，排序后同步更新列表、时间线和监看网格；内部素材与工程关联保持不变。
- 机位编号旁显示代理状态，包括已代理、部分代理、未代理及代理丢失。
- 现场音频使用多个分散窗口核对，抑制观众声和缓慢增益变化；分段分别恢复真实起点，不强制消除停录间隔。
- 同步后自动列出未对齐 / 待检查片段，显示机位、文件名、可信度与原因，支持定位；保留未确认片段原位置。
- 机位列表支持“全部收起 / 全部展开”，刷新后保留展开状态。
- A0 主音频常显，其他音轨可整体或逐轨折叠；拖动音视频分隔条调整轨道高度。
- “工程设置 → 快捷键”可切换当前、DaVinci Resolve、Premiere Pro，并查看键位表；点击“保存设置”后生效并记住选择。
- “工程设置 → 自动保存”可开关定时保存，按秒设置 1–86400 秒的间隔。已命名工程写回原文件；未命名工程保留完整恢复副本，从“工程 → 恢复上次会话”恢复。
- 特效库支持将特效拖到节目／合成轨的视频片段，将转场拖到两个片段的接缝；落点高亮，支持撤销、重做和工程保存。Esc 取消拖放，长时间线边缘可自动横向滚动。
- 右键机位自定义名称，名称随工程保存。
- A0 主音频、A1/A2 对应视频原声；可逐轨静音、同时混音或仅一轨出声，播放与导出一致。
- 后台提取真实波形并缓存，静音轨仍显示波形。
- 编辑区域适配中文输入法下的物理按键，文字框继续支持中文输入。
- M 键添加时间标记，支持定位、删除、保存和撤销重做。
- 统一旧 `.rtxproj` 与独立 `.multicam.json` 打开入口，修复完整工程保存路由，保留帧率精度。
- 改善音频时钟、漂移校正和播放器/波形任务释放。

更新详情与验证边界见 [CHANGELOG.md](CHANGELOG.md)。

## 使用条件

Windows 10/11 64 位。缓存沿用可写的非 C 盘、非系统盘固定磁盘策略，优先 D:。仅有 C 盘的电脑目前无法按该策略正常启动。硬件编解码能力以启动检测和实际驱动为准。

本版尚未做受信任代码签名，Windows 智能应用控制可能拦截。新音轨状态和标记使用工程格式 11；独立音频编辑或非默认吸附/链接设置使用格式 12；删除轨道状态使用格式 13；工程设置和监看布局使用格式 14；时间线导入视图使用格式 16；禁用素材使用格式 17；片段裁切与缩放使用格式 18，时间线视图使用格式 19，调音设置使用格式 20，多机位外层轨道使用格式 21。打开旧工程时会尝试自动升级原文件，并在旁边保留升级前的 .pre-upgrade.bak 备份；升级后请使用本版或兼容后续版本打开。
