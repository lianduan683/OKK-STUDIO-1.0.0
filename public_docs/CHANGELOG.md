# 版本记录

## 1.0.5

### 预渲染与播放状态线

- 在“工程设置 → 预渲染”开启，默认关闭；保存目录及分辨率在本机记忆，支持 540p/720p/1080p/1440p/2160p 预设和自定义偶数宽高，保持工程画幅比例及帧率。
- 固定时间刻度尺下沿显示状态线：黄色表示预计可直接回放，红色表示负载较高或实测 FPS 不足，绿色表示缓存已通过时长、帧率和格式校验。黄色是负载估计，播放时继续校正。
- 暂停且软件空闲时按短区间自动渲染红色部分；播放、导出、生成代理期间暂停后台预渲染，空闲后继续。
- 缓存包含当前调色、转场、字幕及叠加画面。节目监看、GPU 监看及图层合成可消费缓存，原音轨仍使用主时钟；导出仍由原片与工程处理生成。
- 修改画面、原片或分辨率后检查失效缓存；支持已完成缓存复用及损坏后重建。高分辨率缓存的实际播放性能仍取决于设备和磁盘，可在设置中降低分辨率。

- **工程设置**：右下角齿轮或“文件 → 工程设置”打开深色分类设置窗口，支持预设/自定义时间线分辨率、1–240 fps、44.1–192 kHz 采样率及 16/24/32bit、32bit 浮点。工程画幅用于监看与默认交付，音频格式用于监看输出请求和默认 PCM 交付；交付页可单独覆盖输出参数。此类工程及监看布局使用格式 14，继续兼容旧工程。
- **恢复布局**：独立多机位和完整工程均保存网格行列、当前页码；面板位置及分隔比例沿用上次工作区布局并在调整后自动保存。
- **实时播放 FPS**：在“多机位”和右侧监看标题旁分别显示播放吞吐量。左侧取当前页机位的最低值；MPV 按帧位置差值扣除丢帧估算，GPU 和图层输出按实际呈现的新帧计数。暂停、定位和播放器重建会重置统计。
- **时间刻度常显**：向下滚动视频或音频轨道时，时间刻度、标记和播放头手柄固定在时间线上方，仍可点击、拖动定位。
- **删除轨道**：右键视频或音频轨道可选“删除轨道”和“删除空白轨道”。后者批量清理同类型空轨；删除视频保留原声，删除音频保留画面，支持撤销、重做及工程保存。记录已删除轨道的工程使用格式 13，旧格式仍可读取。
- **逐文件代理图标与设置**：素材列表每个视频名前显示代理图标（绿 P 已代理、灰 P 未代理、橙色 ! 代理丢失）；右键视频选择“转代理…”，可设置 H.264 / MP4、DNxHR LB / MOV 或 ProRes Proxy / MOV、分辨率上限、原始或最高 30 fps 帧率及代理存放位置。后台转码完成后自动挂载，导出仍使用原片。
## 1.0.4

- **吸附与链接开关**：时间线工具栏可开关光标对素材边缘、节目切点的吸附；链接开启时视频和机位原声成对选择、移动及删除，关闭后可独立编辑。A0 连续主音频保持独立。开关、独立音频位置与删除状态随工程保存，支持撤销重做。
- **机位代理标志**：多机位编号旁显示“已代理 / 部分代理 n/N / 未代理 / 代理丢失”，识别手动链接、生成代理和已有缓存；状态独立于“代理预览”开关，生成、链接及文件丢失后自动刷新。
- 使用上述非默认开关或独立音频编辑的工程使用多机位格式 12；本版仍支持读取格式 1–11。

## 1.0.3 及后续同步修复

- **现场音频同步修复**：采用带通包络和多个分散窗口交叉确认，改善现场混响、观众声及增益变化下的匹配；分段独立确认真实起点，保留停录间隔与乱序素材的实际位置，不再因个别片段失败而整轨退回。
- **同步待检查明细**：同步后自动列出未确认片段的机位、文件名、可信度与原因，可直接定位；机位标题显示待检查数量，片段名称前标记“未对齐”，未确认片段保留原位置。
- **机位列表一键折叠**：列表上方“全部收起 / 全部展开”切换所有机位，刷新和元数据更新保留各机位展开状态。
- **三套键位**：“布局 → 键位选择”提供三套预设和“键位表”，可即时切换当前、DaVinci Resolve、Premiere Pro，并记住上次选择。原键位保留 C 直接切开；达芬奇 A/B 选择/剃刀、Ctrl+B 切开；PR V/C 选择/剃刀、Ctrl+K 切开。两套新增预设支持 J/K/L 定位与播放、I/O 成片入出点、上下切点导航及 Ctrl+Shift+Z 重做；对照表列出本软件支持的操作。
- **音轨折叠**：A0 主音频保持显示；点击“机位原声”可整体展开/收起其他音轨，点击 A1/A2 等轨头的小三角可单独折叠波形。折叠不改变出声状态。
- **音视频轨道大小调整**：拖动音视频之间的横向分隔条，同时调整两部分的轨道高度；Esc 取消本次调整。折叠再展开可恢复此前的分隔比例。
- **机位自定义名称**：右键机位行即可重命名或恢复默认名称；名称同步显示在素材列表、监看和时间线上，并随工程保存。
- **逐轨音频控制**：A0 为连续主音频，A1、A2 等对应同号视频轨原声。点击轨头切换出声/静音，右键可选“仅此轨出声”；支持多轨混音或全部静音，监听与导出遵循同一设置。
- **真实音频波形**：后台解码原始音频，支持缓存和缩放；静音轨也可查看波形，正确处理反相立体声，无音频或离线素材显示状态提示。
- **中文输入法快捷键适配**：编辑区域按实际按键识别 C、数字键、空格、方向键及 Ctrl 组合键；文字输入框保留中文输入。
- **M 键时间标记**：按 M 或点击“标记 M”在播放头处添加标记；自动对齐帧率，避免重复和长按连发，支持定位、右键删除、保存及撤销重做。
- **修复旧工程打开与保存**：“文件 → 打开工程”同时支持 `.rtxproj` 完整工程和 `.multicam.json`。打开完整工程后，Ctrl+S 保存完整工程，保留原有其他工作区数据；加载时保留 29.97003 等帧率精度。
- **播放与资源释放**：主音频静音时使用活跃机位音频校准时钟，校正其他音轨漂移；删除机位时释放对应音频播放器，关闭工作区时取消波形后台任务。

## 1.0.1

### 同步与机位导入

- 修复参考音轨起始延迟和反相双声道造成的同步偏差；采用有限多窗口匹配，保留不确定结果的提示。
- 同一机位的多个连续视频先按顺序进入同一条视频轨道，再整体平移对齐；帧率量化后保持相邻片段无缝。
- 从文件资源管理器选择视频文件或整个文件夹；文件夹默认导入为一个机位，也提供逐文件创建机位的方式。
- 导入原片文件夹时避免将 Proxy、ProxyMedia、CacheClip 等派生子目录重复当作原片；用户直接指定代理文件夹时按明确选择处理。

### 播放与剪辑

- 修复播放 / 暂停按钮及空格响应，处理播放器状态和键盘焦点变化。
- 修复多机位监看选择与切换操作；透明叠加模式保持独立语义，避免静默修改图层。

### 已有代理

- 支持 Proxy / PRX / 代理前后缀、分辨率标记和保留原扩展名的常见代理名称。
- 同名跨机位原片可通过对应的机位子文件夹消歧；无法唯一确定时保留提示，不猜测绑定。
- 支持达芬奇 Proxy Generator / Proxy Media 的 `机位/Proxy/原片同名.mov`，包括 DNxHR LB MOV 和 ProRes MOV。
- DNxHR LB 在 ffprobe 中的 `codec_name` 显示为 `dnxhd` 是正常的，实际 profile 为 `DNXHR LB`，不会据此拒绝链接。
- 修复原生监看中 DNxHR 代理无法硬件解码时被当作无效代理剔除的问题；预检编码能力，对不支持硬解的代理使用软件解码兼容输出，避免等待硬解加载超时。
- 手动链接支持不同文件名；素材、时间线和单素材机位的明确选中状态可作为原片来源。单机位多段可按选区批量匹配。
- 修复 MKV 视频短于音频时，以容器总时长误判完整代理不匹配的问题。仍拒绝明显裁切、变速或无视频的代理。
- 校验失败原因直接出现在状态栏，详细结果保留在任务日志。

### 安装与兼容

- 主程序直接内置 Setup.exe，移除安装期间 core.zip 的网络下载步骤。
- 继续复用 v1.0.0 的 4 份资源 ZIP，固定地址和 SHA256，支持 `/PAYLOADDIR` 离线组件目录。
- AppId 保持 `OKKSTUDIO.1.0.0`，使用上次安装目录进行升级。
- 当前仍未做受信任的代码签名，未改变 Windows 智能应用控制限制；安装器不修改安全防护。
- 原有非 C 盘、非系统盘固定磁盘缓存要求保留。

### 已验证与边界

代理专项回归已通过 83 项测试，覆盖命名、目录消歧、选区、取消、热挂载、缓存和错误代理拒绝。实际测试：H.264 1280×720/60fps 原片 → DNxHR LB MOV 640×360/30fps，完整 8 秒；ffprobe 确认为 `dnxhd / DNXHR LB / yuv422p`，批量目录匹配和完整时长校验成功。另验证了 ProRes 代理及 MKV 长音频尾场景。

文件夹导入、同步和批量机位的 Tk 集成，以及工程 / 会话相关专项回归均已通过。各测试套件可能覆盖同一功能，不将它们简单相加作为独立功能数量。

这是合成素材上的回归，不代表所有相机格式、长演出工程或所有硬件均已实测。Resolve 内部 Optimized Media / CacheClip 渲染缓存不作为完整代理媒体文件支持。
